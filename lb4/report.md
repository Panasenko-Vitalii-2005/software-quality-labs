\# Лабораторна робота №4



\*\*Тема:\*\* Тестування HTTP API за допомогою Postman



\*\*Виконав:\*\* Панасенко Віталій  

\*\*Група:\*\* 6.1213-2пі



\## Мета роботи



Ознайомитися з можливостями Postman для тестування HTTP API, навчитися створювати GET- та POST-запити, передавати параметри й JSON-дані, а також розробляти автоматизовані перевірки відповідей сервера.



\## Хід роботи



\### 1. Створення колекції



У Postman створено колекцію `Lab 4 - API Testing` зі змінною `baseUrl`, значення якої: `https://postman-echo.com`.



\### 2. Тестування GET-запиту з параметрами



Створено запит `01 GET with Params`:



`GET {{baseUrl}}/get?name=Vitalii\&role=student`



Сервер повернув HTTP-статус `200 OK` та передані параметри у полі `args`.



Реалізовано чотири автоматизовані перевірки:

\- HTTP-статус дорівнює 200.

\- Заголовок `Content-Type` містить `application/json`.

\- Значення параметра `name` дорівнює `Vitalii`.

\- Значення параметра `role` дорівнює `student`.



\*\*Результат:\*\* 4 тести пройдено успішно.



\### 3. Тестування POST-запиту з JSON



Створено запит `02 POST with JSON`:



`POST {{baseUrl}}/post`



Тіло запиту:



```json

{

&#x20; "name": "Vitalii",

&#x20; "role": "student",

&#x20; "course": 4

}

```



Сервер повернув HTTP-статус `200 OK` та отримані дані у JSON-відповіді.



Реалізовано п'ять автоматизованих перевірок:

\- HTTP-статус дорівнює 200.

\- Заголовок `Content-Type` містить `application/json`.

\- Поле `name` містить значення `Vitalii`.

\- Поле `role` містить значення `student`.

\- Поле `course` містить числове значення `4`.



\*\*Результат:\*\* 5 тестів пройдено успішно.



\### 4. Перевірка HTTP-помилки 404



Створено запит `03 GET 404`:



`GET {{baseUrl}}/status/404`



Сервер повернув HTTP-статус `404 Not Found` і JSON-відповідь:



```json

{

&#x20; "status": 404

}

```



Реалізовано дві автоматизовані перевірки:

\- HTTP-статус дорівнює 404.

\- Поле `status` у тілі відповіді дорівнює 404.



\*\*Результат:\*\* 2 тести пройдено успішно. Помилка 404 є очікуваним результатом цього сценарію.
