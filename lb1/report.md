### Аномалія №1

Для користувача `performance_glitch_user` після натискання кнопки `Login` спостерігається затримка приблизно 5 секунд перед відкриттям сторінки Products.

Аномалії присвоєно рівень **Severity: Medium**, оскільки основна функціональність залишається доступною, але швидкодія системи погіршується.

**Priority: Medium**, оскільки проблема негативно впливає на користувацький досвід, проте не блокує роботу із застосунком.

Детальний опис та докази наведено у відповідному GitHub Issue.

### Аномалія №2

Під час авторизації як `problem_user` виявлено, що для різних товарів на сторінці Products відображається однакове зображення собаки, яке не відповідає назвам та описам товарів.

Аномалії присвоєно рівень **Severity: Medium**, оскільки дефект порушує коректне візуальне представлення товарів, але не блокує основну функціональність застосунку.

**Priority: Medium**, оскільки дефект суттєво погіршує сприйняття каталогу користувачем, однак не перешкоджає виконанню основного сценарію роботи.

Детальний опис та скріншот наведено у відповідному GitHub Issue.

### Аномалія №3

Для користувача `error_user` виявлено, що кнопка `Add to cart` не працює для окремих товарів. Після натискання товар не додається до кошика, а кнопка залишається у стані `Add to cart`.

Аномалії присвоєно рівень **Severity: High**, оскільки порушено одну з основних функцій інтернет-магазину — можливість додавання товару до кошика.

**Priority: High**, оскільки дефект безпосередньо перешкоджає користувачеві придбати окремі товари та потребує першочергового виправлення.

Детальний опис та докази наведено у відповідному GitHub Issue.

## Висновок

Під час виконання лабораторної роботи було проведено ручне тестування вебзастосунку SauceDemo з використанням різних тестових облікових записів. Було виконано базовий сценарій роботи системи та виявлено три аномалії різних типів: проблему швидкодії, візуальний дефект та функціональний дефект.

Для кожної виявленої аномалії створено окремий GitHub Issue із зазначенням середовища тестування, кроків відтворення, очікуваного та фактичного результатів, доказів, Severity і Priority. Найбільш суттєвою виявленою проблемою є неможливість додавання окремих товарів до кошика для користувача `error_user`, оскільки вона безпосередньо порушує основний функціональний сценарій застосунку.
