## Функції

- `calculateDiscount()`

## Test Design

### calculateDiscount

Перевірено такі Test Conditions та Test Data:

| Test Condition        | Test Data                  | Expected Result |
| --------------------- | -------------------------- | --------------- |
| Розрахунок знижки 10% | price = 100, percent = 10  | 90              |
| Нижня межа знижки     | price = 100, percent = 0   | 100             |
| Верхня межа знижки    | price = 100, percent = 100 | 0               |
| Від'ємна ціна         | price = -10, percent = 10  | Error           |
| Знижка понад 100%     | price = 100, percent = 101 | Error           |

Для перевірки помилкових аргументів використано assertion `toThrow()`.

### validateQuantity

Застосовано Equivalence Partitioning та Boundary Value Analysis.

**Equivalence Partitions:**

- Значення менше 1: недопустимі.
- Цілі числа від 1 до 10 включно: допустимі.
- Значення більше 10: недопустимі.
- Нецілі числа: недопустимі.

**Boundary Values:**

| Quantity | Expected Result |
| -------- | --------------- |
| 0        | false           |
| 1        | true            |
| 2        | true            |
| 9        | true            |
| 10       | true            |
| 11       | false           |
| 1.5      | false           |

Для виконання семи перевірок використано параметризований `test.for()`.

### getShippingCost

Перевірено три сценарії:

| Total | Expected Result | Умова                 |
| ----- | --------------- | --------------------- |
| 999   | 100             | Сума менша за 1000    |
| 1000  | 0               | Сума не менша за 1000 |
| -1    | Error           | Від'ємна сума         |

Тести перевіряють обидва варіанти вартості доставки та обробку недопустимого значення.

## Висновок

Під час лабораторної роботи створено та виконано 15 автоматизованих модульних тестів для трьох функцій за допомогою Vitest. Водночас 100% Code Coverage не гарантує відсутності дефектів, оскільки цей показник відображає виконання коду тестами, але не підтверджує повноту тестових сценаріїв і правильність очікуваних результатів.
